# Placement Prediction Dashboard

A modern, AI-powered web application built with React + TypeScript and Node.js backend for students to track and optimize their placement preparation journey with **Google Gemini AI** integration.

## 🚀 Features

### Core Functionality
- **Dashboard Overview**: Real-time placement probability, skill metrics, and KPI cards
- **Student Profile Management**: Comprehensive profile with skills, coding profiles, and resume upload
- **AI-Powered 16-Week Roadmap**: Personalized learning path generated by **Google Gemini AI** 🤖
- **Company Matching**: AI-powered recommendations with fit scores and gap analysis
- **Analytics & Optimization**: Data-driven insights with Monte Carlo simulations
- **Progress Tracking**: Track weekly progress and adapt your roadmap

### AI Features (Google Gemini Integration)
- 🤖 **Personalized Roadmap Generation**: AI analyzes your profile and creates a customized 16-week study plan
- 📊 **Smart Weekly Planning**: AI breaks down your preparation into manageable, focused weeks
- 🎯 **Adaptive Learning**: Roadmap adjusts based on your progress and target companies
- 💡 **Actionable Insights**: Get AI-powered recommendations for your preparation

### Technical Highlights
- Modern React 18 with TypeScript
- Node.js + Express backend with Prisma ORM
- **Google Gemini AI** for intelligent roadmap generation
- Material UI components with custom theme
- Recharts for data visualization
- React Query for efficient data fetching
- JWT authentication
- PostgreSQL database (optional - works in mock mode)
- PDF export functionality
- Fully responsive design (mobile, tablet, desktop)

### UI Components

#### KpiCard
Display key metrics with optional trends.

```tsx
<KpiCard
  title="Overall Placement Probability"
  value="82%"
  subtitle="Based on current skills"
  trend={{ value: 8, direction: 'up' }}
  icon={<TrendingUp />}
  color="success"
/>
```

**Props:**
- `title`: Card title
- `value`: Main metric value
- `subtitle`: Optional description
- `trend`: Optional trend indicator
- `icon`: Optional icon
- `color`: Theme color variant

#### GaugeChart
Semi-circular gauge chart for percentage display.

```tsx
<GaugeChart
  value={82}
  label="Overall Readiness"
  color="#2563eb"
  size={200}
/>
```

#### LineChartSkills
Multi-line chart for skill progression over time.

```tsx
<LineChartSkills
  data={skillHistory}
  height={300}
/>
```

**Data format:**
```ts
{
  week: number;
  dsa: number;
  csFundamentals: number;
  systemDesign: number;
  language: number;
  behavioral: number;
}[]
```

#### RadarSkillGapChart
Radar chart comparing current vs target skill levels.

#### WeekCard

## 📊 Data Types & Interfaces

### StudentProfile
```ts
interface StudentProfile {
  id: string;
  name: string;
  college: string;
  branch: string;
  graduationYear: number;
  cgpa: number;
  skills: string[];
  githubUrl?: string;
  leetcodeUrl?: string;
  resumeUrl?: string;
  targets: {
    companies: string[];
    roles: string[];
    minPackageLPA: number;
  };
  integrationStatus: {
    github: 'connected' | 'not-connected' | 'pending';
    leetcode: 'connected' | 'not-connected' | 'pending';
    resume: 'uploaded' | 'not-uploaded' | 'parsing';
  };
}
```

### PlacementSummary
```ts
interface PlacementSummary {
  overallPlacementProb: number; // 0-1
  highPackageProb20LpaPlus: number; // 0-1
  companyProbs: { [company: string]: number };
  totalProblemsSolved: number;
  currentStreak: number;
  lastUpdated: string;
}
```

### Roadmap
```ts
interface Roadmap {
  durationWeeks: number;
  weeklyPlan: WeeklyPlanItem[];
  overallCompletion: number;
  generatedAt: string;
}

interface WeeklyPlanItem {
  week: number;
  focusAreas: string[];
  targets: string[];
  expectedOutcomes: string[];
  completionPercent: number;
  estimatedHours: number;
}
```

```ts

api.regenerateRoadmap()

// Skill Analytics
api.getSkillAnalytics()

// Company Matches
api.getCompanyMatches()

// Optimization Insights
api.getOptimizationInsights()
```

### Real API Integration

To integrate with a real backend:

1. Replace mock functions in `src/api/mockApi.ts`
2. Update API endpoints:

```ts
import axios from 'axios';

const API_BASE_URL = 'https://your-api.com/api';

export const api = {
  async getStudentProfile() {
    const response = await axios.get(`${API_BASE_URL}/student/profile`);
    return response.data;
  },
  // ... other endpoints
};
```
